Build from source ↗

Shastra is an MIT-licensed working prototype. Build locally with macOS 15+, Apple Silicon, Swift 6, Node.js, and npm.

Contribute ↗
Build from source 
git clone https://github.com/arkokoley/shastra.git
cd shastra
(cd Bridge/Claude && npm ci --ignore-scripts --no-audit --no-fund)
swift build
zsh Scripts/package-app.sh
open dist/Shastra.app

Native desktop same-thread control is in progress. Some provider workflows need further live verification. Read the current limits ↗
