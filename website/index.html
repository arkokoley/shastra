A LITTLE LESS CONTEXT SWITCHING

Keep the work together.

From the first question to the next background task, Shastra keeps the project in view.

01 / CONVERSATIONS

Find your thread.

Discover local agent history, group chats by project, and choose a linked continuation when you’re ready to work.

02 / TOOLS

Stay close to the code.

Open files, inspect Git changes, browse a local app, and use an interactive terminal alongside the conversation.

03 / AGENTS

Give work room to run.

Assign background workers, queue follow-ups, use isolated Git worktrees, and review results in the Agents workspace.

SWITCH ACCOUNTS. KEEP YOUR FLOW.

A different account.
The same context.

Choose another saved account right from the chat composer. Keep your project and conversation in view, without restarting Shastra or manually rebuilding the context.

Switch once the current turn finishes. Shastra starts a fresh provider session with the chat’s context. Provider support and live verification vary.

GET STARTED

Make yourself at home.

Build locally on an Apple Silicon Mac with macOS 15+, Swift 6, Node.js, and npm. Install and sign in to the vendor CLI you want to use.

Build from sourceTerminal
git clone https://github.com/arkokoley/shastra.git
cd shastra
(cd Bridge/Claude && npm ci --ignore-scripts --no-audit --no-fund)
swift build
zsh Scripts/package-app.sh
open dist/Shastra.app
